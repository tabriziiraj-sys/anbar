# 🏢 انبارینو - سیستم مدیریت انبار و امور مالی

سیستم مدیریت انبار و امور مالی برای شرکت‌های کوچک - کاملاً فارسی و RTL

## ✨ ویژگی‌ها

- 📦 **مدیریت انبار**: ورود و خروج کالا با کنترل موجودی
- 👥 **طرف حساب‌ها**: مشتریان، فروشندگان و سایر اشخاص
- 💰 **دریافت و پرداخت**: واریزی‌ها، پرداختی‌ها و گردش حساب
- 📊 **گزارش‌های کامل**: موجودی، ورود و خروج، بدهکاران، بستانکاران، هزینه‌ها
- 🖨️ **چاپ حرفه‌ای**: اسناد A4 با سربرگ شرکت
- 📁 **خروجی Excel**: گزارش‌ها به فرمت CSV
- 🔒 **حسابرسی کامل**: ثبت نام کاربر و تاریخ تمام عملیات
- 💾 **ذخیره محلی**: کاملاً آفلاین، بدون نیاز به اینترنت

## 🚀 راه‌اندازی سریع

### روش ۱: اجرای مستقیم (ویندوز)

```bash
start.bat
```

### روش ۲: اجرای مستقیم (لینوکس/مک)

```bash
chmod +x start.sh
./start.sh
```

### روش ۳: دستی

```bash
# نصب وابستگی‌ها
npm install

# ساخت پروژه
npm run build

# اجرای سرور
node server.js
```

## 🌐 دسترسی

پس از راه‌اندازی، در مرورگر باز کنید:

```
http://localhost:3008
```

## 📋 منوی اصلی

### داشبورد
- خلاصه وضعیت انبار و امور مالی
- نمودار ورود و خروج ۱۴ روزه
- هشدار کمبود موجودی
- عملیات اخیر

### اطلاعات پایه
- **اطلاعات شرکت**: نام، لوگو، آدرس، تلفن، کد اقتصادی، شناسه ملی
- **کاربران**: افزودن، ویرایش، فعال/غیرفعال
- **طرف حساب‌ها**: مشتریان، فروشندگان، سایر
- **کالاها**: معرفی کالا با تصویر، قیمت، حداقل موجودی

### انبار
- **ورود کالا**: ثبت سند ورود با چند قلم
- **خروج کالا**: ثبت سند خروج با کنترل موجودی
- **موجودی کالا**: گزارش لحظه‌ای موجودی
- **گردش کالا**: ریز ورود و خروج هر کالا

### طرف حساب‌ها
- **واریزی‌ها**: دریافت از مشتریان
- **پرداختی‌ها**: پرداخت به فروشندگان
- **سایر پرداخت‌ها**: پرداخت‌های متفرقه
- **گردش حساب**: ریز عملیات مالی هر طرف حساب

### فاکتورها و هزینه‌ها
- **خرید کالا**: فاکتورهای خرید کالا
- **فاکتور خدمات**: خرید خدمات و تعمیرات
- **هزینه‌ها**: هزینه‌های جاری (برق، آب، اجاره، ...)
- **سایر پرداخت‌ها**: پرداخت‌های بدون طرف حساب

### گزارشات
- **موجودی کالا**: ارزش ریالی انبار
- **ورود و خروج**: جمع مبالغ ورود و خروج
- **بدهکاران**: طرف حساب‌های بدهکار
- **بستانکاران**: طرف حساب‌های بستانکار
- **واریزی‌ها**: گزارش دریافتی‌ها
- **هزینه‌ها**: تحلیل هزینه‌ها بر اساس نوع
- **عملکرد کاربران**: ماتریس عملیات هر کاربر

### تنظیمات
- **تنظیمات چاپ**: سربرگ، پاصفحه، محل امضاء
- **تنظیمات عمومی**: اجازه موجودی منفی، پشتیبان‌گیری

## 💾 پشتیبان‌گیری

### دریافت فایل پشتیبان
1. وارد **تنظیمات → تنظیمات عمومی** شوید
2. روی **دریافت فایل پشتیبان** کلیک کنید
3. فایل JSON دانلود می‌شود

### بازیابی از فایل پشتیبان
1. وارد **تنظیمات → تنظیمات عمومی** شوید
2. روی **بازیابی از فایل پشتیبان** کلیک کنید
3. فایل JSON را انتخاب کنید

## 🖨️ چاپ اسناد

همه اسناد (ورود، خروج، گزارش‌ها) با سربرگ شرکت روی کاغذ A4 چاپ می‌شوند:

- **سربرگ**: لوگو، نام شرکت، آدرس، تلفن، کد اقتصادی، شناسه ملی
- **پاصفحه**: ثبت‌کننده، تاریخ ثبت، ساعت، محل امضاء

## 📊 خروجی Excel

همه گزارش‌ها و لیست‌ها قابلیت خروجی به فرمت CSV (Excel) دارند:

- با BOM برای نمایش صحیح فارسی در Excel
- قابل باز کردن در Excel، LibreOffice، Google Sheets

## 🛠️ تکنولوژی‌ها

- **React 18** - کتابخانه UI
- **TypeScript** - زبان برنامه‌نویسی
- **Vite** - ابزار build
- **Tailwind CSS 4** - فریمورک CSS
- **Node.js** - سرور توسعه
- **localStorage** - ذخیره‌سازی محلی (معادل SQLite)

## 📝 نکات مهم

1. **ذخیره محلی**: داده‌ها در `localStorage` مرورگر ذخیره می‌شوند
2. **پشتیبان‌گیری**: به‌صورت دوره‌ای فایل پشتیبان بگیرید
3. **آفلاین**: کاملاً بدون نیاز به اینترنت کار می‌کند
4. **حسابرسی**: تمام عملیات با نام کاربر ثبت می‌شود
5. **چاپ**: اسناد با سربرگ شرکت روی A4 چاپ می‌شوند
